### 🎧 Spotify Clone
Clone do Spotify desenvolvido para praticar front-end, com interface inspirada na plataforma original.

---

### ✨ Sobre o projeto
Este projeto foi desenvolvido com o objetivo de praticar desenvolvimento front-end, recriando a interface do Spotify com atenção aos detalhes visuais e à usabilidade.

---

### 🎵 Funcionalidades
- Layout inspirado no Spotify
- Navegação entre seções (Home, Biblioteca, etc)
- Exibição de playlists e músicas
- Componentes reutilizáveis

---

### 🎨 Interface
O design segue o estilo do Spotify, com foco em cores escuras, contraste e organização de conteúdo musical.

---

### 🛠️ Tecnologias utilizadas
- React
- JavaScript
- CSS

---

### 🚀 Como rodar o projeto
```bash
git clone https://github.com/becsnr/spotify.git
cd spotify-clone
npm install
npm run dev
```
