# 🎧 Spotify Clone

Clone da interface do Spotify desenvolvido com React, permitindo navegar por artistas, álbuns e playlists em uma interface inspirada na plataforma original. 
O projeto reproduz a experiência visual do serviço de streaming com foco em responsividade e organização dos componentes.

🌐 <a href="https://becspotify.vercel.app/">Ver Projeto</a>

---

## 🎯 Funcionalidades
- 🎵 Listagem de artistas
- 💿 Exibição de álbuns
- 📂 Navegação por playlists
- 📱 Layout responsivo
- ⚡ Interface inspirada no Spotify

## 🚀 Como Executar

1. Clone o repositório
   
   ```bash
   git clone https://github.com/becsnr/spotify.git
   cd spotify
   ```

2. Instale as dependências

   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento

   ```bash
   npm run dev
   ```

4. Abra o endereço exibido no terminal
